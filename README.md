A Python program that writes one original dad joke to /output/entry.txt for make.fun's "Dad Joke Showdown" bounty.

## How it works

`main.py` is a small deterministic Python 3 program (standard library only, no network, no dependencies). It writes exactly one dad joke — a deadpan, tell-it-out-loud joke with a single clean pun at the end, well under the 200-character limit — to `entry.txt` in the output directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (falling back to `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the joke to `out/entry.txt`. Running it twice produces byte-identical output.
